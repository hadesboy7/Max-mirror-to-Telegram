# Диагностика

## Сначала посмотрите журнал

```bash
# если запущено как служба systemd
journalctl -u max-mirror -n 100 --no-pager

# если запущено вручную — вывод идёт в терминал
```

Мост раз в 30 минут пишет отметку о работе:

```
жив: в беседе видно 29 сообщений; за сессию доставлено новых=3 правок=0 удалений=0; в очереди 0
```

- `в беседе видно 0` при работающем браузере — скорее всего сломались селекторы;
- `в очереди` растёт — Telegram не принимает сообщения;
- отметки нет дольше часа — мост завис, нужен перезапуск.

## Мост не запускается

**`Ошибка конфигурации .env`** — мост сам пишет, что именно не заполнено.
Частые случаи: пустой `TELEGRAM_TARGET_CHAT_IDS`, `MAX_URL` без адреса конкретной
беседы.

**`Не задан TELEGRAM_BOT_TOKEN`** — нет файла `.env` или в нём нет токена.
Проверьте, что запускаете мост из каталога проекта.

**`Executable doesn't exist`** — не установлен браузер:
```bash
python -m playwright install chromium
```

**`ProcessSingleton` или `profile appears to be in use`** — остался замок от
прошлого запуска. При остановленном мосте:
```bash
rm -f max_profile/SingletonLock max_profile/SingletonSocket max_profile/SingletonCookie
```

**`Arguments can not specify page to be opened`** — опечатка в `CHROMIUM_ARGS`:
каждый аргумент должен начинаться с дефиса и не содержать пробелов внутри
значения.

## Мост просит QR-код

Сессия MAX слетела. Мост присылает снимок с QR в первый целевой чат. Отсканируйте
его в приложении MAX: **Настройки → Устройства**.

Если нужно войти заново с нуля:
```bash
# остановите мост, затем:
HEADFUL=1 python bridge_ui.py
```
Откроется окно браузера — отсканируйте QR, откройте нужную беседу, остановите
мост и запустите снова с `HEADFUL=0`.

## Сообщения не приходят

1. **Проверьте, что в беседе вообще пишут.** Молчание беседы — не поломка.
   В журнале отметка «жив» покажет, сколько сообщений мост видит.
2. **Проверьте, что бот может писать в целевой чат.** Для личного чата нужно
   один раз нажать `/start` у бота. Для группы или канала бот должен быть
   участником с правом отправки сообщений.
3. **Проверьте `в очереди`** в отметке «жив». Если число растёт, Telegram
   отклоняет отправку — ищите в журнале строки «Не доставил».

## Мост видит 0 сообщений, хотя беседа открыта

MAX изменил вёрстку. Мост присылает предупреждение об этом. Нужно обновить
селекторы в `.env`. Как узнать новые:

1. Запустите с окном браузера: `HEADFUL=1 CALIBRATE=1 python bridge_ui.py`
2. Откроется окно, войдите и откройте беседу. Через три минуты мост сохранит
   `calib_dump.html` — разметку страницы.
3. Найдите в нём элемент одного сообщения и подберите селекторы:
   `SEL_MSG_ITEM` (контейнер сообщения), `SEL_MSG_AUTHOR`, `SEL_MSG_TEXT`,
   `SEL_MSG_TIME`, `SEL_COMPOSER` (поле ввода).
4. Впишите их в `.env`.

`calib_dump.html` содержит вашу переписку — не публикуйте его.

## Вложения не доходят

- Вложение больше `MEDIA_MAX_BYTES` (20 МБ по умолчанию) — придёт текст с
  пометкой. Увеличьте лимит, если нужно, но помните про память сервера.
- Пришёл текст с пометкой «вложение не удалось получить» — доставка была
  отложена больше 120 секунд, и обращаться к странице стало небезопасно.
  См. `docs/LIMITATIONS.md`, пункт 4.

## Кнопка «Скриншот чата» не отвечает

Ваш числовой id не внесён в `TELEGRAM_ALLOWED_USER_IDS`. Это **отдельный
список** от получателей: быть участником целевого чата недостаточно. Узнать
свой id: напишите @userinfobot.

## Очередь не пустеет

```bash
sqlite3 state.db "SELECT chat_id, state, COUNT(*) FROM deliveries GROUP BY chat_id, state;"
sqlite3 state.db "SELECT chat_id, last_error FROM deliveries WHERE state!='delivered' LIMIT 5;"
```

`last_error` покажет причину. Частое: `Forbidden: bot was blocked by the user`
(получатель заблокировал бота) или `chat not found` (неверный id). После 20
неудачных попыток заявка переходит в состояние `giveup` и перестаёт держать
очередь.

## Мост занимает много памяти

Около 200 МБ приходится на библиотеку aiogram и Playwright, это не утечка.
Сам мост хранит в памяти примерно 2 МБ. На сервере с 1 ГБ ОЗУ мост работает,
но вместе с браузером потребляет 300–500 МБ.
